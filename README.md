# BDAMA KING

A 3D ball-flick action game.

This is a web game created by [Grok](https://grok.com/) using [Node.js](https://nodejs.org/).

---

## Setup & Installation

1. Install Node.js (Version 22 or higher).
2. Open your terminal / shell, navigate to the project's root directory, and run the following command (First time only):
```
   npm install
```
3. Once the installation is complete, start the game server with this command:
```
   npm run dev
```
4. Open your browser and navigate to the displayed address (e.g., `http://192.168.x.x:8080/` or `http://localhost:8080/`[^1]) to start playing!

---

## Game Description

Knock, dodge, or lure all enemies into the holes to win.  
If the player falls in first, it loses a life.

---

## Controls

- Accelerate / Steer : `WASD` or `Arrow` keys
- Emergency Brake : `SPACE` key
- Camera Control : Mouse drag or `Q`/`E` keys

Touch controls are supported for smartphones and mobile devices.

---

[^1]: The server and browser devices must be connected to LAN.
